# QA And Definition Of Done

## Visual QA

Run screenshots at:

- Desktop: 1440x900.
- Wide desktop: 1920x1080.
- Tablet: 834x1194.
- Mobile: 390x844.

Check:

- Hero scene is cinematic immediately.
- It is obvious this is Skylark Exim.
- It is obvious this is Indian seafood export.
- Ocean route feels primary.
- Swordfish and tuna are visible as hero products.
- Shrimp and ponds appear as supporting second-origin story.
- Compass HUD is readable.
- Scroll controls the experience.
- Text does not overlap.
- Canvas is not blank.
- RFQ is usable.

## Cinematic QA

The site fails if:

- It feels like static sections.
- It feels like a generic landing page.
- It feels like a restaurant site.
- It copies a dark trading-site mood too closely.
- It ignores the adventure of the ocean story.
- It shows unsafe or dirty handling.
- The ocean looks like night or storm.
- The compass feels like a game instead of a premium maritime interface.
- The final globe/export sequence feels weak.

## Definition Of Done

The project is done only when:

- The website is implemented, not merely described.
- The entire experience is scroll animated.
- Blender MCP assets are generated, exported, verified, and integrated, unless a tool blocker is documented.
- Higgsfield has been used with the latest Blender collector workflow where available.
- Ocean adventure is the main storyline.
- Fishermen board the ship.
- Compass/time/temperature overlay exists.
- Nets are cast.
- Swordfish and tuna are hero catches.
- Onboard chilled storage is shown.
- Return to port is shown.
- Cold-chain transfer is shown.
- Processing, cutting, freezing, and packing are shown.
- QC and residue testing are shown.
- Cold storage and 700-pallet capacity are shown.
- Reefer container loading is shown.
- Container vessel departure is shown.
- Globe route map is shown.
- RFQ exists.
- Desktop and mobile QA pass.
